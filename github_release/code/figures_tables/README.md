# Reproducing the figures and data tables

Every data figure (Figures 3-6) and every data table (Tables 4-10) of the revised manuscript is generated by
the two scripts in this folder directly from the result files. No figure or table was edited by hand.

## Inputs
- `results_revision/`: output of `run_experiments.py` (uploaded as results_revision.zip)
- `blockchain_run/results_blockchain/`: output of `RUN_ME.sh` (uploaded as blockchain_results_20261019_115609.zip)
- `loadtest_run/results_blockchain/`: output of `RUN_LOADTEST.sh` (uploaded as loadtest_results_20261019_225159.zip)
- `fasttest_run/results_blockchain/`: output of `RUN_FASTTEST.sh` after `RESET_CHAIN.sh` (uploaded as fasttest_results_20261020_014341.zip)

## Run
```bash
unzip results_revision.zip
unzip blockchain_results_20261019_115609.zip
unzip loadtest_results_20261019_225159.zip
unzip fasttest_results_20261020_014341.zip
bash reproduce.sh results_revision blockchain_run/results_blockchain loadtest_run/results_blockchain fasttest_run/results_blockchain reproduced
```
Requirements: Python 3.8+, numpy, pandas, matplotlib. The outputs in the manuscript were produced with: Python 3.12.3, matplotlib 3.10.8, numpy 2.4.4, pandas 3.0.2.
With these versions the outputs are byte-identical to the files listed in MANIFEST.sha256; other matplotlib
versions may give visually identical figures with different bytes.

## What comes from where
| Output | Manuscript | Source files |
|---|---|---|
| fig_six_convergence | Figure 3 | six_uav_traces.csv, six_uav_summary.csv |
| fig_six_maps | Figure 4 | six_uav_final_positions.csv, parameters_used.json (communication radius, compromised set) |
| fig_six_residuals | Figure 5 | six_uav_traces.csv, parameters_used.json (tolerance, warm-up) |
| fig_adaptive | Figure 6 | adaptive_attack_table.csv |
| tab_six_mc | Table 4 | six_uav_mc_table.csv |
| tab_onchain | Table 5 | onchain_summary_all_runs.csv |
| tab_large_main | Table 6 | large_scale_table.csv |
| tab_detection | Table 7 | large_scale_table.csv |
| tab_threshold | Table 8 | threshold_sweep_table.csv, threshold_sweep_runs.csv |
| tab_sensitivity | Table 9 | threshold_sweep_table.csv |
| tab_load | Table 10 | ledger_load_test_summary.csv (load-test run), fast_load_test_summary.csv (optimized run) |

Tables 1-3 are descriptive and were written by hand; their values come from equivocation_demo.json
(gas in Table 2) and from parameters_used.json and chain_metadata.json (Table 3). The verification results quoted
in Sections 5.5-5.6 come from sanity_checks.csv and two_uav_relabelling_example.json.
Figures 1 and 2 are conceptual illustrations, not data figures.

Layout choices that are not data (axis ranges, label offsets in Figure 4, colors) are set in make_figures.py.
